# Reference fixtures

- [The Lantern Crossing](linear-three-nodes/README.md) is a minimal linear story with three nodes and a terminal ending.
- [Tavern at Dusk](tavern-at-dusk/README.md) covers inherited actions and rules, typed command aliases, dialogue interruption/resume, conditional dialogue, inventory, a time-driven rule cascade, two locales, managed image/audio, and JS/Lua/Python source examples.

The action transcripts are semantic expectations for later engine acceptance work. They are not runtime captures. Each fixture contains its own `project.json`, `world.json`, and locale files.
