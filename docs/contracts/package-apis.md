# Package names and public API ownership

All workspace packages use the `@dungeon-scrivener/` scope. A public API has one owner. Cross-package imports use the owner package's public entry point and model types from `@dungeon-scrivener/model`. Internal source paths are not public imports.

| Package | Public responsibility and API boundary |
| --- | --- |
| `@dungeon-scrivener/model` | Owns `packages/model/src/public-types.ts`, canonical schemas, structural validation, semantic reference diagnostics, migrations, contract types, and playable-content fingerprint computation. Types are the only implementation artifact in 1B. |
| `@dungeon-scrivener/vfs` | Owns byte-preserving project files, safe path index/edit operations, ZIP import/export, ZIP feature and extraction budgets, SHA-256 of managed assets. Public operations: `createSnapshot`, `readProjectZip`, `writeProjectZip`. |
| `@dungeon-scrivener/persistence` | Owns IndexedDB recovery only. Public operations: `loadRecovery`, `saveRecovery`, `clearRecovery`. It does not own deliberate project ZIP saves. |
| `@dungeon-scrivener/engine` | Owns immutable session state, validated effects, action dispatch, event/rule queue, node lifecycle, time and randomness, dialogue and inventory state. `createGameEngine(host, compiledScriptBundle)` receives a bundle and `ScriptExecutorApi`; `host.mediaAssets` is the content-hash resolver used for player-view asset metadata. The bundle may be empty. At `createSession(projectId, world, options)`, the engine requires exactly one matching IR for each `world.scripts` declaration, including matching ID, source path, language, and entrypoint. A different world passed later to `dispatchPlayerInput`, `observeClock`, or `dispatchAction` is checked again before execution; a changed script declaration set that does not match the bundle fails with diagnostics and preserves the snapshot. A different world with the same declarations remains compatible at this boundary. Seeded sessions fail creation for an invalid supplied seed or unavailable/invalid seed source; unseeded sessions fail when a random call has no valid entropy or replay source. `createSession` returns `SessionCreationResult`; invalid start clock inputs or a bundle mismatch return diagnostics and no session. `run-script` calls the executor synchronously at its authored effect position. `matchCommandText` normalizes and resolves bounded raw text; `dispatchPlayerInput` routes choices, raw command text, dialogue-option IDs, and use/transfer/equip/unequip inventory operations. `projectDialogueView(manifest, world, locales, snapshot, requestedLocale?)` returns a typed localized dialogue projection or `undefined` when no conversation is active. Inventory inputs target stable stack IDs. `observeClock` accepts bounded host clock/focus/visibility/resume inputs. Transitions return a snapshot, ordered trace, and diagnostics. `getPlayerView` includes resolved typing-sound references and fallback settings. |
| `@dungeon-scrivener/scripting` | Owns JS/Lua/Python subset frontends, IR validation, capability execution, and execution budgets. `ScriptExecutorApi.executeScript(ir, context)` synchronously returns `ScriptExecutionResult`; capabilities submit requests to the engine's provisional transaction and never mutate a snapshot directly. The executor reports bounded instruction use, source-spanned capability/failure trace, or a diagnostic. |
| `@dungeon-scrivener/markdown` | Owns Markdown parse, node-link/asset resolution, bounded node embeds, safe rich AST output, and diagnostics. Public operation: `renderMarkdown`. It does not return trusted raw HTML. |
| `@dungeon-scrivener/media` | Owns content-addressed asset lookup and static image/audio metadata. Public operations: `registerAsset`, `resolveAsset(assetId: ContentDigest): MediaAssetResolution`. A successful resolution verifies the digest and returns media type, byte length, and bytes without exposing a project path; failures return diagnostics. It does not edit or transcode media. |
| `@dungeon-scrivener/i18n` | Owns locale key resolution and default-locale fallback. Public operation: `resolveText`. It does not rewrite source strings. |
| `@dungeon-scrivener/player` | Owns accessible player UI over `PlayerView` and `PlayerInput`. `PlayerView.typingSounds` contains key/key-group mappings, resolved content-hash references, volume, and fallback. The player passes each `assetId` to `MediaAssetApi.resolveAsset` to receive verified WAV bytes; it never guesses a project path. It sends choice IDs, raw command text, or the active conversation/line/option IDs through `dispatchPlayerInput`; it does not construct converted command parameters, store session state, or mutate engine state. |
| `@dungeon-scrivener/player-save` | Owns session snapshot codec, save-slot policy enforcement, compatibility checks, and explicit save ZIP download/import. `encodePlayerSave` returns `Promise<PlayerSaveEncodeResult>`; `decodePlayerSave` returns `Promise<PlayerSaveDecodeResult>`. Both return either a complete success value or diagnostics, never a partial save/session. Encode fails for invalid data or when expanded JSON or final ZIP exceeds 8 MiB. Decode fails for malformed/unsupported ZIP, excess archive or expanded size, malformed JSON, schema violations, or invalid cross-references. `checkSaveCompatibility` returns every mismatched key among project ID, game version, engine version, and content fingerprint. Any mismatch rejects load; decoding is side-effect free, and the importer only replaces the active session after full decode, validation, and compatibility succeed. |
| `@dungeon-scrivener/exporter` | Owns portable game ZIP output from accepted model, IR, media, and player runtime artifacts. Public operation: `exportGame`. |
| `@dungeon-scrivener/sage` | Owns IDE/file-tree controller and text/binary editor integration. It does not own the VFS data representation. |
| `@dungeon-scrivener/apprentice` | Owns graph/form editing commands over model APIs. It does not own a separate project model or engine. |
| `@dungeon-scrivener/diagnostics` | Owns aggregation, path/entity linking, acknowledgment policy, and suggested fixes over diagnostics emitted by owner packages. Public operation: `collectDiagnostics`. |
| `@dungeon-scrivener/debugger` | Owns trace presentation and playtest controls. It reads engine trace data and submits explicitly labeled validated actions; it does not mutate state directly. |
| `@dungeon-scrivener/studio` | Owns the app shell and integration wiring in `apps/studio`. It composes package APIs and owns no duplicate model, parser, player-save codec, or VFS implementation. |

`packages/model/src/public-types.ts` defines shared data types and signatures for model, VFS, engine, script compiler/executor, media, and player-save boundaries. Engine snapshots contain every field required for portable save/resume, including initial and current seeded PRNG state or the complete unseeded outcome log. Transition trace records have a zero-based sequence per action and always include their source and reason. A package may not introduce an overlapping API under another package name.

## Effect and state ownership

Script and UI callers submit `PlayerInput`, resolved `ActionInput`, or typed `Effect` requests. `ScriptEffect` excludes `run-script`, so scripts cannot recursively start scripts. The engine validates requests against the current world and applies state changes atomically within one top-level action. A requested effect is not evidence that state changed. `PlayerView` is a read-only projection produced by the engine. The VFS owns file bytes and paths, not world semantics. The model owns schema/reference diagnostics, not session state.
