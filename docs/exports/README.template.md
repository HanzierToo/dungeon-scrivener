## Player saves

Use the game's save control to download a player save as a separate ZIP file. To continue later, open a compatible copy of this game and import that save through the game's load/import control. Keep the save ZIP somewhere you can find it; the game cannot silently write a save into its extracted folder.

A save can be imported only into the matching project and compatible game and engine versions with the same playable content. The hosted game and an exported copy can share a save when all of these match. An incompatible save is rejected. Keep a copy of the game release that matches your saves.
