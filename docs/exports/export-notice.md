# Export notice

Show this notice when an author starts an export. Substitute the game name and version from the project.

> **Export {{GAME_NAME}} ({{GAME_VERSION}})**
>
> The ZIP will contain a playable copy of this game and its included local assets. Players download and extract the complete ZIP, then open `index.html` in a supported desktop browser with JavaScript enabled. The optional generated README lists the browsers tested for this release; if you omit it, provide that list when sharing the game. Play requires no server or network connection after download. The game cannot silently save into its extracted folder; player saves are separate ZIP downloads that players import later. Share the complete ZIP, and make sure you have permission to distribute the story and bundled assets.
