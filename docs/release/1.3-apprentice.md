# v1.3 Apprentice local verification

Date: 2026-10-02 (Asia/Jakarta). This is evidence for the uncommitted local checkout based on `dc29502`, not a release tag or deployment approval. Existing v1.2 follow-up edits remain in the same working tree.

## What changed

- The Inspector now groups scene text, player choices or commands, and advanced scene settings in reading order. Choices and commands have distinct accents, destructive controls are quieter, and section `?` buttons explain game concepts in place.
- The Inspector can collapse and resize with a pointer or arrow keys. Its expand control fills the viewport with both the map and Inspector. Escape exits the expanded view. Scene and rich-text fields now have a consistent section break and spacing; the formatting toolbar uses recognizable marks for bold, italic, code, headings, quotes, lists, and links.
- Inspector help opens on hover or keyboard focus and is clamped to the viewport. The graph keeps Add scene visible and moves less common operations into Map tools. A node or navigation link has a context menu. The built-in fit icon was replaced with a graph-shaped fit control. Navigation arrowheads are half their previous dimensions.
- Folder nodes have handles. Connecting a folder's lower handle to a scene or another folder's upper handle sets containment. Connecting two scenes creates a playable route. Selecting a folder before adding a node places the new node in it. Folder headings and Inspector guidance explain that folders organize content and can nest, while player routes run between scenes. Folder text and inheritable actions remain available in an advanced disclosure, since the folder itself is not shown during play. Existing model semantics still permit scene parents in hand-authored files; Apprentice's parent picker offers folders to keep its visual workflow clear.
- A new project forks from The Old Gate to the Stone Bridge or Watchtower. The gate route changes state; the watchtower demonstrates the typed `descend` command. The starter layout is saved in `studio/graph-layout.json`. A dismissible Start here card lives in the Inspector so it cannot cover map nodes. Apprentice's mode tour remains replayable but is no longer offered automatically on entering the mode.
- The first-run Studio tour invitation is a compact nonmodal card. The spotlight tour starts only if the user selects it.
- On screens narrower than 600px, the map starts at a legible zoom near the entry scene. The fit control still shows the whole map on demand.
- World now opens with a Translations subsection. It collects locale keys referenced throughout the project, including choice labels, commands, and scene content, and shows saved keys too. Authors can select a language, add another language, search keys, and edit long or multiline text in a full-width editor. Scene text points authors to that subsection. The World sections now use consistent gaps and section boundaries instead of the previous crowded Actors, Inventory, and Time layout.
