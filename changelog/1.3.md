# v1.3, 2026-10-02

## For authors and players

- The starter story branches between the gate and watchtower. The gate demonstrates a state-changing choice, and the watchtower demonstrates a typed `descend` command.
- Apprentice separates scene text, choices/commands, and advanced settings in the Inspector, with clearer help, quieter destructive controls, and recognizable rich-text formatting buttons.
- The map and Inspector can be viewed together in full screen. The Inspector can collapse or resize using a pointer or keyboard; Escape exits the expanded workbench.
- Folder handles establish parent relationships separately from playable scene routes. Folder headings explain inherited actions/rules, and narrow screens open the map at a more readable zoom.
- Translations have a searchable language/key editor with multiline text and language creation. Scene text points authors to the translation editor.
- The initial tour offer is a compact nonmodal card. A dismissible starter guide provides a first experiment, and the main tour remains available for replay.
- Sage adds file search and clearer file operations; the playtest debugger makes state and trace inspection easier to reach.

## For developers

- Expanded Apprentice forms, collection browsing, rich-text editing, and map/Inspector integration operate on the canonical project model.
- Sage search runs through a dedicated worker. Project-file helpers support Studio's editing workflows.
- Browser coverage expanded for folder containment, translation persistence, workbench expansion, responsive maps, and Inspector help.

See the [historical v1.3 verification record](../docs/release/1.3-apprentice.md) for its validation details. Later fixes and features belong to later release notes.
