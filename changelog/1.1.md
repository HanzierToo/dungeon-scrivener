# v1.1, 2026-09-25

## For authors

- Studio gains a clearer home page, project identity header, warm paper editing surfaces, and distinct editing, Playtest, Play, project-download, and game-export controls.
- A first-run tour introduces the actual Studio interface and remembers dismissal or completion. Authors can replay it from the workspace header; Back, Next, Exit, and Escape are available.
- Sage opens `world.json` as a useful starting point. Apprentice exposes the selected scene's text/actions alongside world settings and script declarations.
- The map and Inspector sit side by side on wider screens and stack on narrow screens. Focus styling and reduced-motion support apply to the shell and tour.

## For developers and players

- This release concentrates on the authoring shell and discoverability. The existing player runtime and archive formats remain the foundation rather than introducing a new save or export format.
- Studio integration and browser coverage expand for the tour, editor layout, project import/export, and existing player flows.

See the [historical Studio design record](../docs/ux/1.1-studio-direction.md) for the original direction. Later onboarding and editing changes are described in subsequent release notes.
